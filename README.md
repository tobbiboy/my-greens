# Greens

A responsive multi-page fruit and vegetable catalogue concept built with HTML, CSS, and vanilla JavaScript.

## Preview

After enabling GitHub Pages, the site will be available at [https://tobbiboy.github.io/my-greens/](https://tobbiboy.github.io/my-greens/).

Open `index.html` in a browser, or open the project folder in Visual Studio Code and use Live Server. No build tools or package installation are required.

## Pages

- **Home** — introduction and produce categories
- **About Greens** — the shop concept and how enquiries work
- **Our Promise** — what customers can expect from the catalogue
- **Produce** — example fruit and vegetable categories
- **Trestle Table** — a browsable market-style Kenyan produce catalogue with category filters and example KSh prices
- **For Businesses** — a page for larger produce enquiries
- **Enquire** — a front-end enquiry form

## Run locally

1. Clone or download this repository.
2. Open `index.html` in a browser, or open the folder in Visual Studio Code and start Live Server.

## Deploy with GitHub Pages

1. Push the project to a GitHub repository.
2. Open the repository’s **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder, then save.
5. After deployment completes, open the published URL shown in the Pages settings.

## Before using this as a live shop

- Confirm catalogue products, current prices, stock information, business contact details, and delivery or collection terms. Trestle Table prices are examples and should be updated to match your actual market.
- Connect the enquiry form to a form service or backend; it currently displays a preview message and does not send enquiries.
- Add a payment provider and checkout only if you want customers to pay online.
